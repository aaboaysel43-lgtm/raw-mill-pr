3. إعدادات البريد الإلكتروني

اكتب عناوين To وCC مباشرة، أو استورد قائمة جهات اتصال من Excel/CSV. جهات الاتصال تُحفظ في هذا المتصفح فقط.

جهات الاتصال

الملف يُفضّل أن يحتوي على عمود Email أو E-mail أو البريد الإلكتروني، وعمود Name أو الاسم اختياري. بعد الاستيراد يمكنك إضافة أي جهة إلى To أو CC.

لا توجد جهات اتصال محفوظة بعد.

إضافة صنف يدويًا

سيُحفظ الصنف في قاعدة البيانات الحالية ليظهر في البحث لجميع المستخدمين المصرح لهم.

استيراد أصناف من Excel

اختر ملف Excel بصيغة XLSX أو XLSM أو CSV يحتوي على أعمدة Old code وSAP Code وBin وMaterial Description وعمود المواصفة/الوحدة. سيحاول النظام مطابقة أسماء الأعمدة بالعربية والإنجليزية. إذا تكرر Old Code، سيحدّث بيانات الصنف الموجود بدل إنشاء نسخة مكررة.

مهم: جرّب أولًا بملف صغير من 2–5 أصناف وتأكد من الأكواد والوصف قبل استيراد ملف كامل.

تغيير بيانات الحساب

هذا يغيّر بيانات حساب Supabase الحالي فقط، ولا ينشئ حسابًا جديدًا. قد يطلب النظام تأكيد البريد الجديد برسالة تحقق.

لو تريد تغيير كلمة مرور حساب مستخدم آخر أو إضافة مستخدم جديد، يتم ذلك من Supabase Authentication > Users بصلاحيات المدير. لا تضع كلمة مرور داخل ملفات GitHub.

بيانات الأصناف تُقرأ وتُحفظ في Supabase. ملف Excel يحتوي على عنوان الطلب والمنطقة وتاريخ الإنشاء والبنود. زر Outlook يفتح مسودة فقط؛ أرفق ملف Excel قبل الإرسال.
